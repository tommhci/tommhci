# Hi, I'm Tom

I work at the intersection of **human–computer interaction, interaction design, and AI-assisted systems**. I build prototypes that make complex decisions and unfamiliar interfaces easier to examine.

### Selected work

**[Xu Bing: Epistemic Gallery](https://github.com/tommhci/Xu-Bing-Gallery)** — An interactive exhibition prototype investigating how uncertainty can be meaningful without making navigation confusing. The case study describes three formative think-aloud sessions and a navigation redesign.  
[Live prototype](https://tommhci.github.io/Xu-Bing-Gallery/) · [Design case study](https://github.com/tommhci/Xu-Bing-Gallery/blob/main/CASE_STUDY.md)

**[AI Control Plane](https://github.com/tommhci/ai-control-plane)** — A Windows/PowerShell reference implementation of project onboarding, protected-path hooks, and verifiable checks for AI-assisted development. It is not a supported production release.  
[Repository and setup](https://github.com/tommhci/ai-control-plane)

**[NRS-1 Workbench](https://github.com/tommhci/nrs-mispricing-workbench)** — An academic prototype for auditing AI/semiconductor narratives against engineering evidence, with logged outputs and explicit uncertainty boundaries. The scoring is experimental, not a validated investment signal.  
[Repository](https://github.com/tommhci/nrs-mispricing-workbench)

I care about **working prototypes, documented design decisions, and clear evidence boundaries**.
